# Jordan

A desktop game engine written in Java: as approachable as Roblox Studio, producing standalone games
for Windows, macOS and Linux.

- [Specification](docs/SPECIFICATION.md) — what Jordan is
- [Design](docs/DESIGN.md) — how it is built
- [JordanScript](docs/SCRIPTING.md) — the scripting language
- [Tasks](docs/TASKS.md) — the roadmap

## Building

Requires JDK 25 (Gradle finds it via toolchains).

```
./gradlew build
```
